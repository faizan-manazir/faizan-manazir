## 🚀 Featured Projects

### [HyShield — Hybrid AI-Driven SSH Honeypot](https://github.com/faizan-manazir/HyShield-A-Hybrid-AI-Driven-SSH-Honeypot-Framework-with-Dockerized-Command-Execution)

A hybrid SSH honeypot project combining **Cowrie, Dockerized command execution, AI-driven analysis, and privacy-aware telemetry** for studying attacker behavior.

### [PhishGuard AI — Phishing URL Detector](https://github.com/faizan-manazir/Phishing-Url-Detector)

A machine-learning based phishing detection project combining **URL feature engineering, NLP, domain intelligence, and classification** to identify potentially malicious URLs.

### [AI-Based Insider Threat Detector](https://github.com/faizan-manazir/AI-Based-insider-threat-detector)

A simulated insider-threat detection platform using **rule-based detection and Isolation Forest anomaly detection**, with a FastAPI backend and Next.js dashboard.

### [ESP8266 Deauthentication Attack Detector](https://github.com/faizan-manazir/ESP8266-Deauthentication-Attack-Detector)

A hardware-based wireless security prototype using an **ESP8266** to detect suspicious Wi-Fi deauthentication activity and trigger a local alert.

### [Network Intrusion Detection System](https://github.com/faizan-manazir/CodeAlpha-Network-Intrusion-Detection-System)

A practical project focused on **network traffic monitoring and intrusion detection concepts**.

### [Mediroza Web Penetration Testing](https://github.com/faizan-manazir/Networkwalks-B083-Wk4-Mediroza-Web-Penetration-Testing-Public)

An authorized educational **black-box web penetration-testing assessment** covering reconnaissance, enumeration, authentication testing, SQL injection validation, protected-document analysis, and evidence documentation.
